# UI preview — Mr Satheesh Iype

Static design preview for client review. Deploy this folder as-is to Vercel: Framework preset "Other", no build command, output directory `.` (or set Root Directory to this folder if it sits inside a larger repo).

Start page: `index.html`. All pages are noindex. Forms are demo-only: submitting shows the confirmation state, nothing is sent.

Updating: replace the whole folder with the new export and push. Do not edit files here by hand; changes are made in the design source and re-exported.
